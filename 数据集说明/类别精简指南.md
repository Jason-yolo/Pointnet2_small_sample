# 类别精简指南

本指南说明如何减少 ModelNet40 数据集的类别数量，以及需要修改的文件。

## 需要修改的内容

### 1. 数据文件（data 目录）

需要修改以下三个文件：

#### `data/modelnet40_normal_resampled/modelnet40_shape_names.txt`
- **作用**: 定义所有类别名称
- **修改**: 只保留需要的类别，每行一个类别名
- **示例**: 如果只保留前10个类别，文件内容应该是：
  ```
  airplane
  bathtub
  bed
  bench
  bookshelf
  bottle
  bowl
  car
  chair
  cone
  ```

#### `data/modelnet40_normal_resampled/modelnet40_train.txt`
- **作用**: 训练集文件列表
- **修改**: 只保留选中类别对应的训练数据文件
- **格式**: `类别名_编号`，例如 `airplane_0001`
- **注意**: 需要过滤掉未选中类别的所有数据

#### `data/modelnet40_normal_resampled/modelnet40_test.txt`
- **作用**: 测试集文件列表
- **修改**: 只保留选中类别对应的测试数据文件
- **格式**: `类别名_编号`，例如 `airplane_0627`
- **注意**: 需要过滤掉未选中类别的所有数据

### 2. 代码文件

#### `train_cls.py`
需要修改以下位置：
- **第 41 行**: `def test(model, loader, num_class=40):` → 改为新的类别数
- **第 43 行**: `class_acc = np.zeros((num_class,3))` → 会自动使用新值
- **第 128 行**: `num_class = 40` → 改为新的类别数

#### `test_cls.py`
需要修改以下位置：
- **第 32 行**: `def test(model, loader, num_class=40, vote_num=1):` → 改为新的类别数
- **第 34 行**: `class_acc = np.zeros((num_class,3))` → 会自动使用新值
- **第 41 行**: `vote_pool = torch.zeros(target.size()[0],num_class).cuda()` → 会自动使用新值
- **第 89 行**: `num_class = 40` → 改为新的类别数

## 使用方法

### 方法一：使用自动化脚本（推荐）

1. **编辑 `reduce_classes.py`**：
   - 打开 `reduce_classes.py` 文件
   - 修改 `SELECTED_CLASSES` 列表，选择要保留的类别
   ```python
   SELECTED_CLASSES = [
       'airplane',
       'bathtub',
       'bed',
       # ... 添加或删除类别
   ]
   ```

2. **运行脚本**：
   ```bash
   python reduce_classes.py
   ```

3. **脚本会自动完成**：
   - 备份原始文件（添加 `.backup_original` 后缀）
   - 更新 `modelnet40_shape_names.txt`
   - 过滤 `modelnet40_train.txt` 和 `modelnet40_test.txt`
   - 更新 `train_cls.py` 和 `test_cls.py` 中的 `num_class` 参数

### 方法二：手动修改

#### 步骤 1: 修改类别名称文件
```bash
# 编辑 modelnet40_shape_names.txt，只保留需要的类别
# 例如，只保留前10个类别
```

#### 步骤 2: 过滤训练和测试文件
```bash
# 手动编辑 modelnet40_train.txt，删除不需要的类别
# 手动编辑 modelnet40_test.txt，删除不需要的类别
# 或者使用 Python 脚本过滤
```

#### 步骤 3: 修改代码文件
- 在 `train_cls.py` 中，将 `num_class = 40` 改为新的类别数（例如 `num_class = 10`）
- 在 `test_cls.py` 中，将 `num_class = 40` 改为新的类别数（例如 `num_class = 10`）

## 示例：精简到 10 个类别

假设要保留前 10 个类别：

1. **修改 `reduce_classes.py`**：
   ```python
   SELECTED_CLASSES = [
       'airplane',
       'bathtub',
       'bed',
       'bench',
       'bookshelf',
       'bottle',
       'bowl',
       'car',
       'chair',
       'cone',
   ]
   ```

2. **运行脚本**：
   ```bash
   python reduce_classes.py
   ```

3. **结果**：
   - `modelnet40_shape_names.txt` 只包含 10 个类别
   - `modelnet40_train.txt` 只包含这 10 个类别的训练数据
   - `modelnet40_test.txt` 只包含这 10 个类别的测试数据
   - `train_cls.py` 和 `test_cls.py` 中的 `num_class` 已更新为 10

## 注意事项

1. **备份原始文件**: 脚本会自动备份，文件名为 `原文件名.backup_original`
2. **类别名称**: 确保类别名称与 `modelnet40_shape_names.txt` 中的完全一致（区分大小写）
3. **数据完整性**: 确保选中的类别在训练集和测试集中都有数据
4. **模型兼容性**: 如果使用已训练的模型，需要重新训练，因为类别数改变了
5. **数据加载器**: `ModelNetDataLoader.py` 会自动从 `modelnet40_shape_names.txt` 读取类别，无需修改

## 恢复原始数据

如果需要恢复原始数据：

1. 删除修改后的文件
2. 将备份文件重命名回去：
   ```bash
   # Windows PowerShell
   Rename-Item modelnet40_shape_names.txt.backup_original modelnet40_shape_names.txt
   Rename-Item modelnet40_train.txt.backup_original modelnet40_train.txt
   Rename-Item modelnet40_test.txt.backup_original modelnet40_test.txt
   ```

3. 手动恢复 `train_cls.py` 和 `test_cls.py` 中的 `num_class = 40`

## 常见问题

**Q: 修改后训练报错怎么办？**
A: 检查 `num_class` 是否在所有相关文件中都已更新，确保与类别数量一致。

**Q: 可以保留不连续的类别吗？**
A: 可以，只要在 `SELECTED_CLASSES` 中列出所有要保留的类别即可。

**Q: 修改后需要重新训练吗？**
A: 是的，因为类别数量改变了，模型结构也会改变，必须重新训练。
