# 自定义数据集文件名使用说明

## 📋 概述

现在 `train_cls.py` 和 `test_cls.py` 支持通过命令行参数指定自定义的数据集文件名。如果你重新命名了以下文件，可以通过参数来指定新的文件名：

- `modelnet40_shape_names.txt` - 类别名称文件
- `modelnet40_train.txt` - 训练集文件列表
- `modelnet40_test.txt` - 测试集文件列表

## 🔧 修改内容

### 1. ModelNetDataLoader.py
- 添加了三个可选参数：`shape_names_file`、`train_file`、`test_file`
- 默认值保持为原来的文件名，确保向后兼容

### 2. train_cls.py
- 添加了三个命令行参数：
  - `--shape_names_file`
  - `--train_file`
  - `--test_file`

### 3. test_cls.py
- 添加了三个命令行参数：
  - `--shape_names_file`
  - `--train_file`
  - `--test_file`

## 📖 使用方法

### 示例 1：使用自定义文件名

假设你将文件重命名为：
- `modelnet5_shape_names.txt`
- `modelnet5_train.txt`
- `modelnet5_test.txt`

**训练时：**
```bash
python train_cls.py \
    --model pointnet2_cls_msg \
    --normal \
    --log_dir pointnet2_cls_msg \
    --shape_names_file modelnet5_shape_names.txt \
    --train_file modelnet5_train.txt \
    --test_file modelnet5_test.txt
```

**测试时：**
```bash
python test_cls.py \
    --log_dir pointnet2_cls_msg \
    --normal \
    --shape_names_file modelnet5_shape_names.txt \
    --train_file modelnet5_train.txt \
    --test_file modelnet5_test.txt
```

### 示例 2：只修改部分文件名

如果你只修改了训练集和测试集文件名，类别名称文件保持原样：

```bash
python train_cls.py \
    --model pointnet2_cls_msg \
    --normal \
    --train_file my_train.txt \
    --test_file my_test.txt
```

### 示例 3：使用默认文件名（向后兼容）

如果不指定这些参数，将使用默认的文件名（`modelnet40_*.txt`），与之前的行为完全一致：

```bash
python train_cls.py --model pointnet2_cls_msg --normal
```

## ⚠️ 注意事项

1. **文件路径**：所有文件名都是相对于数据目录（`data/modelnet40_normal_resampled/`）的，不需要包含完整路径。

2. **文件格式**：确保自定义的文件格式与原始文件格式一致：
   - `shape_names_file`：每行一个类别名称
   - `train_file` / `test_file`：每行一个文件名（不含扩展名），格式为 `类别名_编号`

3. **类别数量**：如果修改了类别数量，记得同时修改 `train_cls.py` 和 `test_cls.py` 中的 `num_class` 参数，或者通过其他方式（如从类别名称文件自动读取）来设置。

4. **数据一致性**：确保：
   - `shape_names_file` 中的类别名称与训练/测试文件中的类别名称匹配
   - 训练/测试文件中引用的点云文件实际存在于对应的类别目录中

## 🔍 参数说明

### train_cls.py 新增参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--shape_names_file` | str | `modelnet40_shape_names.txt` | 类别名称文件 |
| `--train_file` | str | `modelnet40_train.txt` | 训练集文件列表 |
| `--test_file` | str | `modelnet40_test.txt` | 测试集文件列表 |

### test_cls.py 新增参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--shape_names_file` | str | `modelnet40_shape_names.txt` | 类别名称文件 |
| `--train_file` | str | `modelnet40_train.txt` | 训练集文件列表（用于数据加载器） |
| `--test_file` | str | `modelnet40_test.txt` | 测试集文件列表 |

## 📝 完整示例

假设你使用 `reduce_classes.py` 生成了精简后的数据集文件：
- `modelnet5_shape_names.txt`
- `modelnet5_train.txt`
- `modelnet5_test.txt`

**完整的训练命令：**
```bash
python train_cls.py \
    --model pointnet2_cls_msg \
    --normal \
    --log_dir pointnet5_cls_msg \
    --batch_size 16 \
    --epoch 200 \
    --num_point 1024 \
    --shape_names_file modelnet5_shape_names.txt \
    --train_file modelnet5_train.txt \
    --test_file modelnet5_test.txt
```

**完整的测试命令：**
```bash
python test_cls.py \
    --log_dir pointnet5_cls_msg \
    --normal \
    --batch_size 24 \
    --num_point 1024 \
    --num_votes 3 \
    --shape_names_file modelnet5_shape_names.txt \
    --train_file modelnet5_train.txt \
    --test_file modelnet5_test.txt
```

## ✅ 验证

运行后，检查日志输出中是否显示正确的数据集大小：
```
The size of train data is [训练集样本数]
The size of test data is [测试集样本数]
```

如果数据加载成功，这些数字应该与你的自定义文件列表中的样本数一致。
