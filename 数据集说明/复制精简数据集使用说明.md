# 复制精简数据集到新文件夹使用说明

## 📋 功能说明

`copy_reduced_dataset.py` 脚本可以将 `reduce_classes.py` 精简后的数据复制到一个新的独立文件夹，这样：
- ✅ 保留原始完整数据集不变
- ✅ 创建独立精简数据集，方便管理和使用
- ✅ 可以同时保留多个不同版本的精简数据集

## 🚀 使用步骤

### 1. 确保已运行 reduce_classes.py

首先确保已经运行过 `reduce_classes.py` 生成了精简后的文件列表：
- `data/modelnet40_normal_resampled/modelnet40_shape_names.txt`
- `data/modelnet40_normal_resampled/modelnet40_train.txt`
- `data/modelnet40_normal_resampled/modelnet40_test.txt`

### 2. 配置输出目录（可选）

编辑 `copy_reduced_dataset.py`，修改配置区域：

```python
# 输出数据目录（新文件夹）
OUTPUT_DATA_DIR = 'data/modelnet5_normal_resampled'  # 可以自定义名称
```

例如：
- `data/modelnet5_normal_resampled` - 5个类别
- `data/modelnet10_normal_resampled` - 10个类别
- `data/modelnet_custom_normal_resampled` - 自定义名称

### 3. 运行脚本

```bash
python copy_reduced_dataset.py
```

### 4. 确认操作

如果输出目录已存在，脚本会询问是否删除并重新创建：
```
输出目录 data/modelnet5_normal_resampled 已存在，是否删除并重新创建？(y/n):
```

输入 `y` 继续，输入 `n` 取消。

## 🔧 使用精简后的数据集训练

复制完成后，使用以下命令训练：

### 方法1：使用自定义文件名参数

```bash
python train_cls.py --model pointnet2_cls_msg --normal --log_dir pointnet5_cls_msg --shape_names_file modelnet5_shape_names.txt --train_file modelnet5_train.txt --test_file modelnet5_test.txt
```

**注意**：需要修改 `train_cls.py` 中的 `DATA_PATH` 为新的目录，或者修改脚本支持自定义数据路径。

### 方法2：修改 train_cls.py 的数据路径（推荐）

修改 `train_cls.py` 中的 `DATA_PATH`：

```python
# 原代码
DATA_PATH = 'data/modelnet40_normal_resampled/'

# 修改为
DATA_PATH = 'data/modelnet5_normal_resampled/'
```

然后直接运行：

```bash
python train_cls.py --model pointnet2_cls_msg --normal --log_dir pointnet5_cls_msg --shape_names_file modelnet5_shape_names.txt --train_file modelnet5_train.txt --test_file modelnet5_test.txt
```

## ⚙️ 高级配置

### 自定义输出文件名

如果需要自定义输出文件的名称，可以修改脚本中的：

```python
# 输出文件列表名称
OUTPUT_SHAPE_NAMES_FILE = os.path.join(OUTPUT_DATA_DIR, 'modelnet5_shape_names.txt')
OUTPUT_TRAIN_FILE = os.path.join(OUTPUT_DATA_DIR, 'modelnet5_train.txt')
OUTPUT_TEST_FILE = os.path.join(OUTPUT_DATA_DIR, 'modelnet5_test.txt')
```

例如改为：
```python
OUTPUT_SHAPE_NAMES_FILE = os.path.join(OUTPUT_DATA_DIR, 'my_shape_names.txt')
OUTPUT_TRAIN_FILE = os.path.join(OUTPUT_DATA_DIR, 'my_train.txt')
OUTPUT_TEST_FILE = os.path.join(OUTPUT_DATA_DIR, 'my_test.txt')
```

## ⚠️ 注意事项

1. **磁盘空间**：确保有足够的磁盘空间存储精简后的数据集
2. **文件完整性**：如果复制过程中出现失败，检查源文件是否存在
3. **路径配置**：使用新数据集时，记得更新 `train_cls.py` 和 `test_cls.py` 中的数据路径或文件名参数
4. **类别数量**：确保 `train_cls.py` 中的 `num_class` 与精简后的类别数量一致

## 🔄 恢复原始数据集

如果需要恢复原始数据集，`reduce_classes.py` 已经备份了原始文件（`.backup_original` 后缀），可以手动恢复。

## 💡 使用场景

- 同时保留多个不同版本的精简数据集（如5类、10类、20类）
- 在不影响原始数据的情况下进行实验
- 将精简数据集分享给他人
- 在不同项目中使用不同规模的数据集
