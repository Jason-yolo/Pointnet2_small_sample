## 🚀 运行训练命令

由于 `reduce_classes.py` 直接更新了原始文件名（`modelnet40_*.txt`），这些文件名正好是 `train_cls.py` 的默认值，所以你可以直接运行：

### 基础训练命令

```bash
python train_cls.py --model pointnet2_cls_msg --normal --log_dir pointnet5_cls_msg
```

### 完整训练命令（推荐）

```bash
python train_cls.py \
    --model pointnet2_cls_msg \
    --normal \
    --log_dir pointnet5_cls_msg \
    --batch_size 16 \
    --epoch 200 \
    --num_point 1024 \
    --learning_rate 0.001 \
    --gpu 0
```

### 参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| `--model` | `pointnet2_cls_msg` | 使用的模型（或 `pointnet2_cls_ssg`） |
| `--normal` | - | 使用法向量信息（必须添加此标志） |
| `--log_dir` | `pointnet5_cls_msg` | 实验日志目录（可自定义） |
| `--batch_size` | `16` | 批次大小（可根据GPU内存调整） |
| `--epoch` | `200` | 训练轮数 |
| `--num_point` | `1024` | 每个点云的采样点数 |
| `--learning_rate` | `0.001` | 学习率 |
| `--gpu` | `0` | 使用的GPU编号 |

```bash

    --model pointnet2_cls_msg \
    --normal \
    --log_dir pointnet5_cls_msg \
    --shape_names_file modelnet5_shape_names.txt \
    --train_file modelnet5_train.txt \
    --test_file modelnet5_test.txt
```

## ⚠️ 常见问题

### 问题1：GPU内存不足
**解决方案**：减小 `--batch_size`（例如改为 8 或 4）

### 问题2：训练速度慢
**解决方案**：
- 检查 `--num_workers` 参数（默认8，可根据CPU核心数调整）
- 确保使用了 `--normal` 参数（如果数据包含法向量）

### 问题3：类别数量不匹配
**错误信息**：`RuntimeError: Expected input batch_size (...) to match target batch_size (...)`
**解决方案**：确保 `train_cls.py` 中 `num_class` 与类别名称文件中的类别数一致
